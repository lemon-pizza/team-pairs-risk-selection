# 팀 페어 트레이딩의 제한적 중복 선정

팀 베이스라인의 후보 필터, 체결, 비용 계산을 유지하고 페어 선정만 바꾼 연구 코드다. 2016-01-04~2024-12-31의 20페어 상한 실험, 상한 해제, 1~6개월 재선정 주기 비교를 담았다.

| 실험 | 재선정 | 전체 상한 | 배분 |
|---|---|---|---|
| 기본 | 6개월 | 20 | 구간 시작 NAV/20, 빈 슬롯 현금 |
| 상한 해제 | 6개월 | 없음 | 구간 시작 NAV/K, K는 실제 선정 수 |
| 주기 비교 | 1~6개월 | 20 | 구간 시작 NAV/20, 빈 슬롯 현금 |

각 구간에서 공적분 점수 `−EG t-stat`의 합을 최대화한다. 직전 12개월의 비용 전 일별 NAV 수익률을 재생해 계산한 표본분산이 해당 구간의 점수순 탐욕 비중복 기준을 넘지 않도록 한다. 종목별 포함 상한은 1~5개, 섹터 상한은 4페어다. 같은 섹터끼리만 후보가 되므로 종목 상한 4와 5의 가능 집합이 같다. 후보는 팀의 기존 필터를 통과한 전체 페어다.

거래는 팀 원본 엔진으로 실행한다. 종가 신호를 다음 거래일 종가에 체결하고, 각 구간 말에 포지션을 청산한다. 비용 전과 실제 양쪽 레그 주문대금에 편도 5bp를 부과한 비용 후를 각각 계산한다. 상세 실험 조건은 [프로토콜](EXTENSIONS_PROTOCOL_KO.md)에 있다.

## 재현

Python 3.13과 팀 베이스라인 저장소 접근 권한이 필요하다. 아래 명령은 이 저장소를 복제한 폴더에서 실행한다.

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
git clone https://github.com/parameter031212/sp500-pairs-trading.git vendor/sp500-pairs-trading
git -C vendor/sp500-pairs-trading checkout --detach e95685820b7a279798f81b4f7b2662956de7dae0
```

가격(`date`와 종목별 가격), 과거 S&P 500 구성(`date,tickers`), 섹터 매핑(`ticker,sector`) CSV를 각각 지정한다. 원본 CSV는 별도로 준비한다. 실행 시 원본 팀 코드의 Git 파일 해시와 입력 CSV의 SHA-256을 확인한다. 노션 실험에 사용한 입력 해시는 [reference.json](reference.json)에 있다.

```bash
python run_experiment.py \
  --prices /path/to/prices.csv \
  --membership /path/to/membership.csv \
  --sectors /path/to/sectors.csv \
  --output results/published \
  --mode replay --arm all
```

- `--mode replay`는 확정 선정 및 형성기 추정치를 담은 `frozen_selections.json.gz`를 읽고 원래 거래 엔진으로 재계산한다. 누적수익·연변동성·샤프·최대낙폭·거래 수를 기존 결과와 자동 대조한다.
- `--mode solve`는 같은 설정으로 입력 CSV에서 후보, 위험 기준, 페어를 새로 계산한다. 탐색 시간이 제한된 해는 공개 표와 달라질 수 있다. 구간별 선정 JSON에 위험과 최적성 격차가 남는다. `--solver-seconds`는 각 선정의 SCIP 탐색 시간 설정이다.
- `--arm base`, `--arm uncapped`, `--arm cadence`로 실행 범위를 고를 수 있다. 출력 경로는 새 폴더를 지정한다. `comparison.csv`와 각 모형의 일별 NAV, 거래 및 선정 목록이 생성된다.

[84개 백테스트 결과](reference_results.csv)에는 7개 실험 조건, 각 6개 선정 모형과 2개 비용 조건을 담았다. 원 실험의 최적화 1,415개 중 1,329개는 전역 최적성을 수치 허용오차 내에서 확인했다. 나머지는 형성기간 분산 상한을 충족하는 실행 가능한 해이며 최대 상대 점수 격차는 1.010%였다.

형성기간 분산은 같은 기간에 적합한 계수로 산출한 표본 내 위험 추정이다. 결과에는 원자료의 NBL 합병 전후 가격·종목 식별 문제와 정적 섹터 분류의 한계가 남아 있다. 재선정 주기의 우열은 같은 자료에서 비교한 탐색 결과다.
